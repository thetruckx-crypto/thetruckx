# THE TRUCKX Archive Directory

This directory stores archived, deprecated, and historical project artifacts that are preserved for audit and compliance reference but omitted from active production execution paths.

## Directory Structure

* `/archive/backups/`: Full verified transactional database backups and storage manifests taken before schema or data maintenance operations.
* `/archive/legacy-screens/`: Archived legacy mobile screen components that were superseded by modern workflow hubs.
* `/archive/mock-data/`: Retired mock JSON payloads, offline seed samples, and development-only test records.
* `/archive/test-fixtures/`: Historical load-test fixtures and static verification payloads.
* `/archive/obsolete-components/`: Retired UI prototypes, legacy decorations, and unused visual mockups.
* `/archive/old-scripts/`: Obsolete one-off scratch scripts and deprecated database inspection utilities.
* `/archive/deprecated-assets/`: Legacy graphic prototypes replaced by official vector brand assets.
